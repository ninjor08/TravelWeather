# TravelWeather - HERRERA DARIO
## Descripción
Aplicación móvil desarrollada con React Native y Expo que permite registrar destinos de viaje y consultar su clima actual mediante OpenWeather.

## Funcionalidades
- Registro e inicio de sesión con Firebase.
- Registro de destinos con ciudad, país y coordenadas.
- Almacenamiento y sincronización de datos en Firestore.
- Consulta de temperatura, clima y humedad.

## Tecnologías
React Native, Expo, TypeScript, Firebase y OpenWeather API.

## Instrucciones de ejecución
1. Descargar el proyecto y abrirlo en Visual Studio Code.
2. Instalar las dependencias:

Reemplazar `TU_API_KEY` por una clave válida de [OpenWeather](https://openweathermap.org/api).
Abrir la aplicación con Expo Go o un emulador Android.

## Nota
La clave de OpenWeather no se incluye por seguridad. La aplicación requiere conexión a Internet para consultar el clima y utilizar Firebase.
